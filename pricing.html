About point usage

Each reading or command you connect is a point, and points are what you pay for. Forecast depth, interval and code run time can change how many a routine draws on.

Learn more about point usage →

Shared point pool

Points are shared across your account. Routines, forecasts, code, Link and the SDK all draw on the same pool, with no separate budget by product.

Scales with what you run

Simple schedules stay simple to price. If you add finer intervals, longer forecasts or heavier code, usage reflects it. The trade is yours.

Meet the platform

With your plan you get the whole platform for running buildings. Each part makes the others stronger, so a reading can become a decision and a decision a routine.
