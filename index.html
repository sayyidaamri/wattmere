Next gen routines · Pilot

Run sequences reliably on Wattmere

A routine is a control sequence that does its job across your systems without someone nudging it each day. Next gen routines turn what you sketched into a tested sequence with branches, limits and recovery when something trips.

Features

Set a trigger once and the routine runs on the gateway, even when the line is down.

Every routine has a manager that spots a failed step, proposes a fix and can apply it.

Repeated judgement becomes a fixed step, so you only pay for thinking where it helps.

The graduated control difference

Graduated control is how Wattmere keeps buildings steady and savings real. You describe the result, Wattmere suggests where judgement helps, and then tightens or loosens the routine as conditions change, removing guesswork from steps that should run the same way each day but adding it back when the unexpected happens.

Scheduled:

Morning start

You write the steps. Every weekday the floor wakes at six and rests at seven, the same way every time.

Scheduled + forecast:

Weather start

The forecast picks tonight’s start time instead of a fixed clock. Fans, valves and checks still run as fixed steps.

Scheduled + operator:

Comfort triage

An operator reads the zone and judges urgency, then hands off. Urgent rooms go to an engineer, the rest are put right.

Fully self-tuning:

Peak day

An operator works across cooling, storage and lighting using your limits, deciding what to move and what to raise with you.
