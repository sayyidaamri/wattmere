Work in code with the Wattmere SDK

Call Halcyon VAV from services, scripts or operators. Wattmere handles drivers, units and limits.

Install

npm install @wattmere/sdk
npx wattmere login

Run an action

import { connect } from "@wattmere/sdk";

const site = await connect("north-campus");
const unit = await site.find("halcyon-vav");

await unit.write("setpoint", 21.5, {
  limit: { min: 20, max: 24 },
  release: "2h",
});
